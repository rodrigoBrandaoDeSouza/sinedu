# App Android — pós-MVP

Fora do escopo do MVP (ver [decisões D1](../decisoes-mvp.md)). Quando entrar:

- Kotlin + Jetpack Compose, autenticação por token contra a mesma API.
- **Proibido** cachear localmente dados de Saúde e Proteção/Sigilo.
- Mesmas regras de autorização — o app não recebe nada que o perfil não possa ver.
